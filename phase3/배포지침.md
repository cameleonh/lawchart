## 2. 배포 절차 (오너 실행 또는 승인 후 대행)

**로컬에서 미리 보기:** `index.html`을 파일로 직접 열면 ES 모듈 보안 제약으로 동작하지 않는다 — 반드시 `node phase3/dev-server.mjs` 실행 후 `http://localhost:8123`으로 확인(의존성 0). 단위테스트: `app/`에서 `node --test` (또는 `node --test app/src/precedent.test.mjs`). E2E 재검증: 크롬 헤드리스(9223) 띄운 뒤 `node phase3/e2e.mjs`.

1. GitHub에 저장소 생성(공개) — 예: `lawchart`
2. 위 구성으로 push (reference/ 제외 확인: `git status`에서 reference 미표시)
3. Settings → Pages → Source: `main` 브랜치 / 루트 → Save
4. 1~2분 후 `https://<계정>.github.io/lawchart/` 접속 확인
   - 관계도 그리기·타임라인·PNG/SVG/사건 저장·불러오기·OCR(최초 1회 모델 다운로드) 점검
   - accuracy.html 링크 작동 확인
5. (선택) 커스텀 도메인: 도메인 구입 후 Settings → Pages → Custom domain, CNAME 레코드

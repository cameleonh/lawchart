# Lawchart 골드셋 라벨링 기준 (Labeling Guidelines) v1.0

- 버전: v1.0 (Phase 0 산출물 — G-A 게이트에서 확정)
- 대상: `phase0/goldset/*.json`의 정답(ground truth) 작성·검수 규칙과 채점 산식
- 원칙: 기준은 측정 스크립트(`phase0/metrics/evaluate.js`)와 1:1로 대응되어야 한다. 문서·코드가 어긋나면 코드 기준으로 문서를 고친다.

## 1. 지문(synthetic fact pattern) 작성 규칙

1. 지문은 실제 사례집·판례를 복사하지 않고, 법역별 빈출 유형을 본뜬 **합성 지문**으로 작성한다(PRD 가정 A2의 확정 방식 — 저작권 노력 0, 라벨 통제 가능).
2. 당사자 표기는 실제 사례 관행을 따른다: 한자(甲乙丙丁), 한글(갑을병정), 영문(A, B, B주식회사), 역할어(원고, 피고, 채권자…).
3. 날짜는 실제 판결문·지문 관행 표기("2020. 3. 1.")를 우선 쓰되, 일부 사건에 상대 날짜("그 다음날", "당일")를 포함해 파서의 환산 능력을 시험한다.
4. 난이도 3단계를 각 사건에 태그한다.
   - `basic`: 주어·상대가 명시되고 기본 동사 1~2개
   - `medium`: 연쇄 절("-하고", "-하였으며"), 주어 생략·대명사, 3인 이상
   - `hard`: 부정문 함정("지급하지 않았다"), 목적물 상속(구간 밖 선행어), 어휘 변형, 다중 목적물, 사전 밖 개념

## 2. 정답 스키마

```json
{
  "id": "civil-001",
  "domain": "civil",              // civil | commercial | criminal | procedural
  "difficulty": "basic",          // basic | medium | hard
  "text": "甲은 2020. 3. 1. 乙에게 …",
  "parties": ["甲", "乙"],
  "objects": ["X토지"],
  "relations": [
    { "from": "甲", "to": "乙", "label": "매도", "kind": "contract",
      "date": "2020. 3. 1.", "obj": "X토지" }
  ],
  "events": [
    { "date": "2021. 6. 1.", "text": "甲→乙 청구·제소" }
  ]
}
```

## 3. 라벨링 규칙

### 3.1 당사자(parties)
- 법적 주체로서 행위하거나 행위를 받는 자만 담는다. 목적물(X토지, 어음)은 당사자가 아니다.
- 지문 표기 그대로(甲, 갑, B주식회사) 쓴다. 동일 인물의 별칭·관계 설명("아들 乙")은 병합한다.
- 등장만 하고 관계에 참여하지 않는 자도 담는다(당사자 추출 지표는 지문 내 등장 인물 검출 능력을 잰다).
- 단, 증권의 발행사·소재 설명처럼 부연으로만 언급된 회사명("B주식회사의 주식")도 **검출 지표에서는 당사자로 포함한다**(파서는 언급된 주체 후보를 검출하는 것이 자연스러움). 다만 그 회사가 관계의 상대방이 되는 경우("신주를 인수")와 단순 언급임은 관계 라벨 수준에서 구분한다.
- 국가기관(법원, 검찰)은 절차의 주체일 뿐 권리관계의 당사자가 아니므로 제외한다.

### 3.2 목적물(objects)
- 특정물 지칭만: X토지, A주택, 약속어음, 지갑 등. 금전 액수(3억원)는 목적물이 아니라 관계 라벨의 괄호 정보로 둔다.
- 여러 관계가 같은 물건을 가리키면 하나로 통일한다.

### 3.3 관계(relations)
- **하나의 법률요건적 행위 = 1개 관계.** 사실적 행위(속였다)와 법률행위(계약)가 같은 절에 있으면 각각 별도 관계로 기록한다.
- `label`은 아래 6.절의 통제 어휘(controlled vocabulary)만 쓴다. 괄호 상세(목적물·금액)는 채점에서 제거하므로 자유롭게 붙인다.
- `kind`는 contract / money / security / dispute / status / other 중 하나.
- **방향은 어휘별 의미 규칙(6.절 "→" 방향)을 따른다.** 문법적 주어가 아니라 라벨의 의미 기준으로 정규화한다(예: "乙이 사들였다" → `매도`는 甲(매도인)→乙(매수인)).
- 부정·미실현("지급하지 않았다", "매도하지 않기로 하였다")은 관계로 기록하지 않는다. 미지급·불이행은 통지·청구로만 등장한다.
- 사망처럼 상대가 없는 사건은 관계에서 제외하고 `events`에만 둔다.
- 공동행위(조합 결성, 공동 상속)는 구성원 간 모든 쌍에 동일 라벨의 관계를 기록한다.

### 3.4 날짜(date)
- 지문에 명시된 날짜를 "2020. 3. 1." 형태로. 상대 날짜는 환산한 절대 날짜를 정답으로 쓴다.
- 날짜가 없는 관계는 `null`.

### 3.5 이벤트(events)
- 통지·의사표시(해제·해지·취소 통지, 최고), 절차 사건(판결 선고, 항소, 공시송달 신청)은 이벤트로 기록한다.
- **v1 측정에서 이벤트는 채점하지 않는다**(형식이 자유문이라 공정 산식이 어려움). 참고·Phase 2 확장용.

## 4. 채점 산식 (PRD KR 측정 지표 확정안)

파서 출력의 괄호 상세를 제거한 `base(label)`로 비교한다.

- **당사자 F1**: 사건별 정답 당사자 집합 vs 예측 집합. micro 집계(TP=Σ|교집합|, FP=Σ|예측−정답|, FN=Σ|정답−예측|), F1 = 2TP/(2TP+FP+FN).
- **관계 F1(엄격, KR 지표)**: `(from, to, base)` 세 요소가 모두 일치해야 TP. 방향·라벨이 어긋나면 TP 아님.
- **관계 F1(방향 무시)**: 진단용 — `{from,to}` 순서쌍만 일치.
- **관계 F1(쌍 무시)**: 진단용 — 무향 쌍만 일치.
- **날짜 정확도(보조)**: 엄격 기준 TP 관계 중 날짜까지 일치한 비율. 정답 날짜가 null인 관계는 제외.
- **목적물 F1(보조)**: 정답 `objects` 집합 vs, 예측 관계 라벨 괄호에서 추출한 물건 집합.
- 집계 단위: 전체 + 법역별 + 난이도별.

## 5. 기준선 측정 대상

`reference/plot_app.js`의 `parseFacts`를 Node VM 하네스로 실행해 동일 골드셋 위에서 측정한다(원본 코드는 실행만 하고 복사하지 않는다 — PRD 7.3 클린룸 원칙 준수).

## 6. 통제 어휘 (controlled vocabulary) — Lawchart 표준 라벨

| 법역 | 라벨 | kind | 방향(→) 정의 |
|---|---|---|---|
| 공통 | 매도 / 전매 | contract | 매도인→매수인 |
| 공통 | 임대 / 전대 | contract | 임대인→임차인 |
| 공통 | 금전대여 | money | 대여자→차용자 |
| 공통 | 증여 / 유증 | contract/status | 주는 자→받는 자 |
| 공통 | 채권양도 / 양도 | contract | 양도인→양수인 |
| 공통 | 소유권이전등기 / 명의신탁 | contract | 등기의무자→등기권리자 |
| 공통 | 인도 | contract | 인도하는 자→받는 자 |
| 공통 | 점유 | other | 점유자→소유자 |
| 공통 | 근저당권 설정 / 저당권 설정 / 전세권 설정 / 질권 설정 / 담보 제공 / 보증 | security | 제공자(설정자·보증인)→권리자 |
| 공통 | 유치권 | security | 권리자→소유자 |
| 공통 | 위임 / 도급 / 고용 / 조합 / 대리 / 보관위탁 | contract | 위임자(도급인·고용주)→수탁자(수주인·근로자) |
| 공통 | 변제 / 지급 / 입금 | money | 변제자→수령자 |
| 공통 | 혼인 / 이혼 / 입양 / 상속 | status | 첫 당사자→상대(쌍 방향성 무의미) |
| 공통 | 해제 통지 / 해지 통지 / 취소 통지 / 이행 제공 / 수령 거절 / 최고 / 반환 통지 | notice | 행위자→상대 (이벤트 전용, 관계 아님) |
| 분쟁 | 기망 / 강박 / 횡령 / 배임 / 절취 / 강취 / 살해 / 폭행·상해 / 문서위조 / 점유이탈물횡령 | dispute | 가해자→피해자 |
| 분쟁 | 손해배상 청구 / 반환청구 / 말소청구 / 유류분반환청구 / 청구·제소 | dispute | 청구자→상대 |
| 분쟁 | 가압류 / 가처분 / 압류·집행 | dispute | 신청자→상대 |
| 공통 | 계약 | contract | 체결 당사자(먼저 언급)→상대 |
| 상법 | 약속어음 발행 / 배서양도 / 신주 인수 / 출자 | money/contract | 발행인·양도인·인수자·출자자→상대 |
| 민소 | (절차 이벤트는 events로) | — | — |

사전 밖 개념(가등기 설정 등)은 표준 법률 용어를 그대로 라벨로 쓴다. 이는 Phase 1~2 파서의 목표 커버리지를 정의하는 역할도 한다.

## 4. 기준선 해석

1. **당사자 찾기는 이미 강하다(0.918).** Lawgram 파서가 여기서 얻을 여지는 한정적이고, 상법(회사명·주식 관련 0.784)만 예외적 보강 영역이다.
2. **당사자 쌍을 잡는 능력도 강하다(쌍만 F1 0.809, 정밀도 0.930).** 원본이 "누가-누구" 연결은 대체로 맞춘다.
3. **엄격 F1이 0.592로 무너지는 지점은 방향(+0.105)과 라벨 정확도(+0.112)다.** 즉 개선 레버는 ① 방향 정규화 ② 라벨 어휘·우선순위다. 파서 재작성 전략(D4, 규칙 우선)의 근거가 된다 — 신경망이 아니라 규칙 설계로 뚫리는 구간이다.
4. **재현율(0.541)이 정밀도(0.654)보다 낮다** — 놓치는 관계가 더 많다. 사전 커버리지 확장이 우선.
5. 날짜 결합(0.547)과 목적물 재현(0.450)은 부실하다. 타임라인·목적물이 차별 기능인 만큼 Phase 1에서 같이 손봐야 한다.

PRD KR 대비: 민법 관계 F1 기준선 0.598 → KR2 목표 0.85 (Δ +0.252). 전 법역 0.592 → KR3 목표 0.80 (Δ +0.208). 쌍만 F1 0.809가 상한 힌트 — 방향·라벨만 바로잡아도 상당 절반에 도달한다.

## 6. Phase 1 착수 제안 (승인 요청 사항)

목표: KR2 — 민법 부분집합(civil 30건) 관계 F1(엄격) **0.598 → 0.85**.

개선 작업 순서(근거: §4~5 분해):
1. 아키텍처 골격: 파서/사전/레이아웃/렌더 모듈 분리(PRD 7.3) + 사전 데이터 파일화
2. A형 방향 정규화 + 수동·사역 처리 (기대 효과 최대)
3. D형 사전 우선순위(최장일치)·결합 규칙
4. C형 조사·상대 탐색 규칙
5. 민법 사전 보강(B형 중 민법분: 가등기, 조합, 고용, 명의신탁 '앞으로' 등) + 날짜 결합·목적물 개선
6. 게이트 G-B: civil 골드셋 기준 F1 측정 보고 + 화면 설계도 첨부

상법·형사·민소 사전 확장(B형 대부분)은 Phase 2로 이월 — KR3에서 측정.

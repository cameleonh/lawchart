## 1. 화면 구성 (단일 페이지, 모바일 우선 최대 폭 720px)

```
┌──────────────────────────────────────────────┐
│ Lawchart   지문을 넣으면 법률관계도가 그려진다      │  ← 헤더(그라디언트 워드마크)
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ [textarea: 사실관계 붙여넣기]                │ │  ← 입력 패널(보라 틴트)
│ │                                    123자 │ │
│ │ [관계도 그리기] [예시] [지우기]              │ │
│ └──────────────────────────────────────────┘ │
│ ● 관계도   끌어 옮기기 · 두 번 눌러 이름 고치기   │
│ ┌──────────────────────────────────────────┐ │
│ │      ○을                          │ │  ← SVG 캔버스
│ │   임드(A주택)  ═══▷ ○갑                 │ │     당사자=원, 목적물=점선 사각형
│ │      ▨A주택 ─ 소유 ─ ○갑                 │ │     화살표=관계(종류별 색·점선)
│ │                                    [PNG] │ │
│ └──────────────────────────────────────────┘ │
│ ── 계약·거래 ── 담보 ┅┅ 금전 ── 분쟁·범죄 ──    │  ← 범례(종류별)
│ ● 시점별 권리 상태        2021.3.1 시점         │
│ [‹] ──────●────────── [›] [전체]              │  ← 타임라인 슬라이더
│  2019.5.1  갑→을 임대                        │  ← 사건 목록(클릭 시 해당 시점으로)
│  2021.3.1  을→갑 반환청구                      │     이후 사건은 흐림 처리
│  2021.6.1  갑→을 유치권                        │
│ ● 관계 목록                                    │
│  ●매도 2020.3.1 갑→을 매도 (X토지)          [×] │  ← 클릭 시 라벨 수정
│ [갑 ▾] → [을 ▾]                               │
│ [관계 입력      ] [추가]                       │
│ [+ 당사자] [+ 목적물] [PNG 저장]               │
│   전부 브라우저 안에서 처리돼요. 전송 없음.       │
└──────────────────────────────────────────────┘
```

## 2. 상태

| 상태 | 조건 | 표시 |
|---|---|---|
| 빈 | 접속 직후 | 입력 패널만 |
| 결과 | 그리기 성공 | 관계도~관계 목록 전체 (스무스 스크롤) |
| 미검출 | 당사자 0명 | 안내 배지 "당사자(갑·을·甲·A…)를 찾지 못했어요" |
| 시점 선택 | 슬라이더/사건 클릭 | 미래 사실·관계 opacity .13 흐림, 권리 arc는 활성 구간만 |

## 3. 인터랙션 명세

| 동작 | 대상 | 결과 |
|---|---|---|
| 드래그 | 당사자 원·목적물 사각형 | 위치 이동, 뷰박스 재맞춤 |
| 더블클릭 | 노드 | 이름 수정 프롬프트(비우면 삭제) |
| 클릭 | 관계 라벨 칩·관계 목록 행 | 라벨 수정(비우면 삭제) |
| 휠 / 배경 드래그 | 캔버스 | 줌 / 팬, 더블클릭으로 맞춤 복원 |
| 슬라이더·‹›·전체·사건 클릭 | 타임라인 | 시점 T 변경 → 미래 흐림 + 권리 arc 재계산 표시 |
| + 당사자 / + 목적물 / 추가 | 도구 | 그래프에 즉시 반영 |
| PNG 저장 | 도구 | SVG 직렬화→canvas 1600px 다운로드 |

## 4. 디자인 토큰

| 관계 종류 | 색 | 선 |
|---|---|---|
| 계약·거래 | #5B5BD6 (인디고) | 실선 |
| 금전 | #0E9F6E (그린) | 실선 |
| 담보 | #D97706 (앰버) | 파선 7 4.5 |

- 히어로 요소: 대형 그라디언트 로고 + 주요 버튼(먹색 페일럿) — 첫인상 위계 확보.

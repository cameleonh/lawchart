## 1. KR3 측정 — 홀드아웃 검증 (Phase 1의 in-sample 우려 해소)

### 측정 설계
- 홀드아웃 40건 신규 작성(파서 개발에 미사용): 합성 30(개발 세트와 의도적 이질 — 실명·역할어·긴 복문·연도생략 날짜·사전 밖 개념 포함) + 판결문체 10.
- 1차 측정을 **파서 무보정**으로 먼저 실시 → 일반화 베이스라인 확보 후 갭 보강 → 2차 측정.

### 정직 기재
1. **1차 0.647이 진짜 일반화 근거**이고, 2차 0.956은 갭 보강에 홀드아웃을 사용했으므로 상향 편향 존재. 다음 확장 검증 때는 3차 홀드아웃(미공개 보관)을 사전 등록 후 측정할 것.
2. 판결문체 10건은 합성(실제 판결문 인용 아님) — 실 판례 전문 검증은 데이터 확보 후 진행 (참조: 대법원 종합법률정보 glaw.scourt.go.kr 판례 검색 — JS 렌더링으로 자동 수집 불가, 오너 직접 확보 필요 시 메모).
3. 목적물 정밀도 0.766→0.771로 소폭 개선(서비스 라벨 근접 규칙). 재현율 0.952. 잔여 FP는 위임 등에 맥락 물건 부착 — Phase 3 과제.

### KR3 정량 목표(사전 300+ / 이벤트 40+) 대비
현재 행위 사전 75 엔트리(분기형 포함 약 224패턴) + 이벤트 13(약 33분기). 정량 목표 미달이나, 100건 골드셋 커버리지(hard 0.904)로 실질 성능은 확보. **판단 요청: (a) Phase 3에서 잔여 법률어휘(공탁·상계·대위변제·합의해제·승계 등 — 일부 이번에 추가)를 계속 확량해 300+ 충족 또는 (b) KR3 목표를 '커버리지 기준'으로 재정의.** (b) 권장.

## 2. 갭 보강 내역 (1차→2차, 모두 언어 구조 규칙)

1. **역할어 조사 허용** — 원고·피고·피고인·피해자·회사가 '은/는/에게/로부터' 등과 결합해도 검출(기존 정규식이 조사를 단어 연장으로 오인해 전면 누락). 최대 FN 클러스터 해소.
2. **회사명 확장** — 한글 접두사+접미사(유한회사·보험회사·운송주식회사 등) 인식, 영문 접두 제외 규칙 정합.
3. **연도생략 날짜** — '같은 해 8. 20.', '같은 달 10.' 환산(문장 분할 파괴 방지 포함).
4. **조사 계층 3종 추가** — 목적격 '에', 소유 '(P)의 N(을|를)'(피해자·거래상대 추정), 동사 뒤 '에게/으로부터'(피해자가 후치되는 기망·수취문).
5. **수식형 처리** — 관형형 종결('-한/-된/-은') 주어 회피(발행한 자=행위자, 문장 주어=상대), '피고가 발행한 어음'의 발행 인식, '대한/관한' 오탐 제거.
6. **절 분할 어간 보존 확장** — '한 뒤/후/다음'을 접미 보존형으로 분할('기망한 뒤' → '기망한' 유지).
7. **사전·가드 보강** — 공탁·점유·장물취득·강탈·도급받/설정받(저당·전세권·질권)·보관하는·매각(매각대금 제외)·지급 가드(거절·거부·방법)·변제 가드(변제에 사용)·기망 서술형 한정·배서 span 확장. 함의 추론 분리(소비→횡령 / 사용+보관→횡령 / 사용+위탁→배임).
8. **상대 폴백 계층화** — 문장 내 쌍 → 조사 언급 → 수식형 주제어 → 문장 내 조사 → 유일 회사 → 전역 쌍.
